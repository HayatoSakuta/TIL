# 20260113_Unicodeのコードポイント

Unicodeでは各文字に対して整数値のコードポイントを割り振っており、
仕様書などでは慣習的に16進数表記で表現されるケースが標準である。
10進数表記など、別の表記が使用されるケースもあるが、あくまでも表記の差であり、
本質的には同一のUnicodeコードポイント（整数値）を指定しているだけ。

```java
// 「A」のUnicodeコードポイントはU+0041（←16進数表記）
char c1 = 65;     // 10進数で表現しているだけ
char c2 = 0x41;   // 16進数で表現しているだけ
```
