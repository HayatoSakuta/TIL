- Unicodeでは、中国、台湾、日本、韓国の漢字全量に対し、字体がほとんど同じものは統合して扱う。統合後の漢字集合を、CJK統合漢字という（China, Japan, Korea）。
- 統合漢字では、統合前の元の規格で区別されている文字は、統合されない。
- JIS X 0213とUnicodeの関係に関する注意点は3つ存在する。
  - 1. JIS X 0213の一部の文字はUnicodeのBMP外（2面）に位置する。すなわち、JIS X 0213の文字をUnicodeで扱う場合、ソフトウェアはBMP外にも対応する必要がある。
  - 2. JIS X 0213では符号位置が与えられていたアイヌ語用文字や鼻濁音用文字は、Uniodeでは符号位置を与えられておらず、「 `か` + `゜` 」のように、結合文字を使用して表現する必要がある。
  - 3. JIS X 0213で区別される互換漢字は、Unicodeでは正規化により1文字に統合されてしまう。
- Unicodeは絵文字に対して符号位置を与えている。
- 絵文字は、絵文字そのものを表す符号位置に対し、修飾用の符号位置を与えることで、いわゆる絵文字の見た目となる。
- ISO/IEC 2022において図形文字は0x21から始まるが、JIS X 0208における区点番号は1から始まる。そのため、JIS X 0208の区番号or点番号に対し、差分の0x20を加えることで、ISO/IEC 2022の符号位置に変換することができる。
- Unicodeは符号化文字集合。群、面、区、点の4次元で符合位置を定める。群は00-7F、面は各群に00-FF、区は各面に00-FF、点は各区に00-FF。
- 郡00の面00を基本多言語面（BMP）と呼ぶ。一般的に使われる文字はBMPに含まれる。
- UTF-16は、基本的には16ビットで1文字を表す。上位8ビットを区、下位8ビットを点と考えて良い。ただし、これはBMPの話。BMP外の文字は、サロゲートペアを用いて4バイトで1文字を表す。サロゲートペアは上位サロゲート（8ビット）、下位サロゲート（8ビット）の、合わせて2バイト。
- UTF-16は、基本的には1文字2バイトだが、上位バイトと下位バイトの順序をBOMで指定できる。
- UTF-32もUnicodeの文字符号化方式である。4バイトで1文字を表す。なので、サロゲートペアは使用しない、、、はず。
