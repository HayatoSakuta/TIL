- Unicodeでは、中国、台湾、日本、韓国の漢字全量に対し、字体がほとんど同じものは統合して扱う。統合後の漢字集合を、CJK統合漢字という（China, Japan, Korea）。
- 統合漢字では、統合前の元の規格で区別されている文字は、統合されない。
- JIS X 0213とUnicodeの関係に関する注意点は3つ存在する。
  - 1. JIS X 0213の一部の文字はUnicodeのBMP外（2面）に位置する。すなわち、JIS X 0213の文字をUnicodeで扱う場合、ソフトウェアはBMP外にも対応する必要がある。
  - 2. JIS X 0213では符号位置が与えられていたアイヌ語用文字や鼻濁音用文字は、Uniodeでは符号位置を与えられておらず、「 `か` + `゜` 」のように、結合文字を使用して表現する必要がある。
  - 3. JIS X 0213で区別される互換漢字は、Unicodeでは正規化により1文字に統合されてしまう。
- Unicodeは絵文字に対して符号位置を与えている。
- 絵文字は、絵文字そのものを表す符号位置に対し、修飾用の符号位置を与えることで、いわゆる絵文字の見た目となる。
