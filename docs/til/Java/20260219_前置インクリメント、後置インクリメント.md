# 20260219_前置インクリメント、後置インクリメント

Javaには変数の値を1増やすためのインクリメント演算子`++`が存在する。
インクリメント演算子は変数の前または後に置くことができ、前後で挙動が異なるため注意が必要。

```java
//前置インクリメント
int a = 1;
int b = ++a; // b = 2（aのインクリメントが先に評価される）

//後置インクリメント
int a = 1;
int b = a++; // b = 1（aのインクリメントが後から評価される）

//その他の例
int a = 1;
System.out.println(a++ + ++a); // 4
```
