- logbackとは、Javaのログ出力用ライブラリである。
- System.out.println()の代わりに、ログ出力場所やログレベルを、設定ファイルで定義できる。
- 設定ファイルでは、例えば、loggerを定義する。対象パッケージやログレベルを定義する。
- Loggerクラスとは、ズバリ、ログ出力する人のことである。
- Loggerクラスはlogbackが提供するクラスではなく、slf4jが提供する点に注意。
- slf4jはログ出力機能のインターフェースみたいなもので、その実装みたいなものの一つとして、logbackが存在する。logbackの代わりに使うとしたら、log4j2などが存在する。
