# 20260207_bit論理積

整数同士のbit論理積を取る際は、&演算子を使用する。

```java
// 5は2進数表記で101
5 & (1<<0) // 101(2)と001(2)の論理積なので、結果は001(2)
5 & (1<<1) // 101(2)と010(2)の論理積なので、結果は000(2)
5 & (1<<2) // 101(2)と100(2)の論理積なので、結果は100(2)

// nビット目が立っているかどうかの判定
boolean isSetN = ( 5 & (1<<n) ) != 0;
```
