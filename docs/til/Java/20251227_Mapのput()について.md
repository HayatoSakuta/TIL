# 20251227_Mapのput()について

Javaの連想配列Mapにはputメソッドがある。
これは、連想配列に要素を追加するメソッドだが、指定したキーが既に存在する場合は更新する。

```java
HashMap<String,Integer> map = new HashMap<>();
map.put("key1",1); // key1はmapに存在しないため普通に追加される。
map.put("key1",2); // key1は既にmapに存在するため、更新される。
```
