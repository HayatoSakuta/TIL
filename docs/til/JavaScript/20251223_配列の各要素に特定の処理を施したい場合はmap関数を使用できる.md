# 20251223_配列の各要素に特定の処理を施したい場合はmap関数を使用できる

配列の各処理に特定の処理を施した新たな配列を得たい場合、map関数を使用することで、すっきりと実装できる。

```jsx
const arr = ['a','b','c'];
// 各要素を大文字化する
// 方法①：コールバック関数を記述
const newArr1 = arr.map(function(element){return element.toUpperCase()});
// 方法②：アロー関数を使用
const newArr2 = arr.map(element => element.toUpperCase());
```
